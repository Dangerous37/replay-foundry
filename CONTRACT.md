# Recovery rehearsal contract
A scenario supplies an ordered immutable delivery log. Each entry includes attempt ID, operation key, positive integer units and outcome (rejected, lost_ack, confirmed). Rejected attempts have no effect. A lost acknowledgment represents a committed effect without a worker receipt. A confirmed attempt has both. The historical destination honored keys if historicalGuard is true. A rehearsal selects unresolved operation keys and a recovery policy. Compare observed effects with the expected one effect per key and block a plan that overshoots or leaves a deficit. Never execute external requests.
